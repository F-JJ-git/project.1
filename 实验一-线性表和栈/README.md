# 实验一：线性表和栈

本目录用于整理实验一相关代码。

## 1.1 线性表

### 已完成：顺序存储结构

文件：`1.1-顺序表.cpp`

已实现：

- 顺序表初始化
- 批量建表
- 按位取值
- 按 ISBN 查找
- 插入
- 删除
- 两个非递减有序顺序表归并
- 输出
- 清空
- `switch-case` 菜单交互

### 使用说明

程序启动后，先选择 **1 初始化顺序表**，再选择其他操作。

归并操作要求两个顺序表本身已经按照 ISBN 非递减排列，归并算法不会自动排序。
