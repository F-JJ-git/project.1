# 实验一 线性表和栈

本目录整理实验一最终报告中的 7 份交互式 C++ 程序，涵盖两种线性表、两种栈以及栈的三个应用。各源文件与报告代码核对一致，均可单独编译运行。

## 编译和运行

使用 Visual Studio 2022 创建 C++ 控制台项目，将需要运行的一个源文件加入项目，选择 C++17，启用 `/utf-8`。每个源文件都有自己的 `main()`，分别运行即可。Windows 下程序会设置控制台 UTF-8 编码。

也可以在 Visual Studio 开发者命令提示符中进入 `报告代码` 目录，编译其中一题：

```text
cl /nologo /EHsc /std:c++17 /W4 /utf-8 "01_顺序表.cpp" /Fe:seq_list.exe
seq_list.exe
```

使用配套输入文件重现完整操作：

```text
seq_list.exe < "测试输入\01_顺序表.txt"
```

其他程序按同样方法单独编译。7 个程序均已通过 VS2022 编译及配套输入检查。

## 交互约定

### 线性表

两种线性表使用相同菜单：`1 初始化、2 建表、3 取值、4 查找、5 插入、6 删除、7 归并、8 输出、9 清空、0 退出`。

位序从 1 开始；按 ISBN 查找时返回第一次出现的位序，0 表示未找到。录入一本教材时，依次输入 ISBN、出版社、作者、价格，每个字段占一行。出版社和作者可以含空格，ISBN 不能为空，价格须为有限非负数。

顺序表需先初始化，容量为 1000。单链表启动时已是空表，按需分配结点，菜单未设置固定容量上限。建表会替换当前内容。归并时输入第二张表，两张表都必须已按 ISBN 字典序非递减排列；程序验证顺序，保留重复 ISBN，输出归并结果，并保留当前表。顺序表归并后的总长度不能超过 1000。

顺序表底层 `ClearList()` 释放数组；菜单中的初始化和清空会再建立一个可用的空表。单链表清空数据结点，保留头结点。

### 栈

两种栈使用相同菜单：`1 初始化/清空、2 入栈、3 出栈、4 取顶、5 判空、6 元素数量、0 退出`。入栈数据为整数；取顶不删除元素，空栈出栈或取顶会报告失败。

顺序栈启动时需输入 1 至 1000 的容量，达到所选容量后拒绝入栈。链栈按需申请结点，程序未设置固定容量限制。

### 表达式

三个程序每次读取一整行，输入 `exit` 退出。

- 括号匹配只检查 `()`、`[]`、`{}`，忽略其他字符；无括号或空行视为括号匹配。待匹配左括号最多可同时压入 1000 个，超过此容量会返回不匹配。
- 中缀转后缀支持单个数字 `0` 至 `9`、二元 `+ - * /`、三种分组括号和空白。输出用空格分隔，`* /` 优先于 `+ -`，同级按左结合处理。多位数、小数输入、一元正负号、隐式乘法及非法字符会报错；运算符栈容量为 1000。
- 后缀求值按字符识别数字，支持 `0` 至 `9` 和 `+ - * /`，可忽略空白。例如 `23+` 与 `2 3 +` 都得到 5，其中 `23` 表示两个操作数。输入的多位数、小数和负数不能作为单个操作数；计算中间值与结果可为小数或负数。程序检查操作数不足、剩余元素不唯一、除零、非法字符及非有限结果。
