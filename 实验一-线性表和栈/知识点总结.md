# 实验一知识点总结

实验一把线性表的两种存储结构和栈的基本操作联系起来，再用栈完成括号匹配与表达式处理。学习时需要区分逻辑结构、存储方式和操作规则：顺序表与单链表表示同一种线性关系，栈进一步规定只能在栈顶插入和删除。

## 顺序表和单链表

顺序表用连续数组存放教材记录，逻辑位序 `i` 对应数组下标 `i - 1`。按位取值可直接访问；插入、删除需要移动后续元素。单链表使用带头结点的结构，数据从 `head->next` 开始；插入或删除前先找到前驱，再改变指针关系。

| 对比项 | 顺序表 | 带头结点单链表 |
| --- | --- | --- |
| 存储 | 连续数组，实验容量为 1000 | 按需申请结点，结点位置不必连续 |
| 按位取值 | O(1) | O(n)，需要从表头向后寻找 |
| 按 ISBN 查找 | O(n) | O(n) |
| 按位插入、删除 | 最坏 O(n)，主要成本为移动元素 | 最坏 O(n)，主要成本为寻找前驱；已知前驱后改变链接为 O(1) |
| 建表 | O(n)，写入数组 | O(n)，尾插法保留尾指针，逐个建立结点 |
| 有序归并 | O(m+n)，写入结果数组 | O(m+n)，为结果新建结点 |
| 清空 | 本实现释放容量数组，菜单再初始化 | O(n)，逐个释放数据结点，保留头结点 |

复杂度将单条教材记录的复制和 ISBN 比较视为常数成本；若字符串长度随规模变化，还需计入字符串操作成本。

顺序表分配或释放数组时会构造、析构容量 C 个 `Book` 对象，相应成本为 O(C)。链表菜单通过 `values()` 生成 `vector` 再输出，除 O(n) 输出时间外，还使用 O(n) 临时空间。

插入位序合法范围为 `1..n+1`，取值和删除为 `1..n`。头结点使首元素的插入、删除也可统一为修改前驱结点的 `next`，但它本身不计入表长。

## 两个有序表的归并

同时观察两张表当前未处理的第一条记录，比较 ISBN，将较小的一条加入结果并向后移动；某一张表结束后，追加另一张表的剩余元素。每条记录处理一次，所以总时间为 O(m+n)。

本实验比较的是字符串字典序，因此示例用等长的 `001`、`002`、`003`。例如字符串 `"10"` 在 `"2"` 前面，不能把字典序误当成整数大小顺序。

两个输入表都须预先有序，归并不负责排序。相等时先取第一张表的记录，重复 ISBN 会保留。链表实现采用复制式归并，为输出创建新结点，两个输入表不被拆分；顺序表也使用独立的结果数组。

## 顺序栈和链栈

栈遵循后进先出。依次压入 10、20、30，连续出栈应得到 30、20、10；取栈顶 30 后，元素数量仍为 3。

| 对比项 | 顺序栈 | 链栈 |
| --- | --- | --- |
| 栈顶表示 | `top` 是元素数量，也是下一次写入的下标；非空时栈顶下标为 `top - 1` | `top` 指向栈顶结点 |
| 入栈 | 先判满，再写入数组并增加 `top` | 新建结点，令其 `next` 指向原栈顶，再更新 `top` |
| 出栈 | 先判空，再读取栈顶并减少 `top` | 读取栈顶、移动指针、释放原栈顶结点 |
| 取顶、判空、数量 | O(1) | O(1)，数量由计数器维护 |
| 入栈、出栈 | O(1) | O(1)，按结点分配和释放视为常数成本 |
| 容量 | 固定；基础操作程序可选择 1 至 1000，底层数组长度为 1000 | 按需申请，受可用内存限制 |
| 清空 | 将 `top` 置零，O(1) | 逐个释放结点，O(n) |

报告中的链表和链栈删除了复制构造及复制赋值，防止默认浅拷贝使多个对象释放同一批结点。此前“学习记录/栈”中的 `SqStack` 则专门实现了深拷贝，两份示例体现不同的资源管理方式。

## 括号匹配

从左向右扫描，遇左括号入栈；遇右括号时，弹出最近尚未匹配的左括号并检查类型。右括号出现时若栈为空、类型不相符，或扫描结束后仍有左括号未处理，都表示不匹配。

例如 `([)]` 的右小括号遇到的是左方括号，因此失败。没有括号的 `2+3` 可以通过括号检查，但这只能说明括号结构正确，不能代替完整的表达式语法检查。

扫描时间为 O(n)，所需栈空间随最大嵌套层数增长；本实现的顺序栈容量为 1000。

## 中缀转后缀

数字直接加入输出，左括号入运算符栈，右括号触发弹栈直到对应左括号。遇到新运算符时，先输出栈中优先级大于或等于它的运算符，再将新运算符入栈。这个“大于或等于”保证同级运算符的左结合性：

| 中缀 | 后缀 | 含义 |
| --- | --- | --- |
| `2+3*4` | `2 3 4 * +` | 先乘后加 |
| `(2+3)*4` | `2 3 + 4 *` | 括号先算 |
| `8-3-2` | `8 3 - 2 -` | `(8-3)-2` |
| `8/4/2` | `8 4 / 2 /` | `(8/4)/2` |

`expectOperand` 记录当前应当出现操作数还是运算符，用于拒绝连续运算符、相邻数字、空括号以及隐式乘法。每个符号至多入栈、出栈一次，时间为 O(n)，输出和辅助栈空间为 O(n)，其中栈容量固定为 1000。

## 后缀求值

数字入操作数栈；遇运算符时先弹出右操作数 `b`，再弹出左操作数 `a`，计算 `a op b` 并把结果压回。减法和除法必须保留这个顺序。输入结束后应恰好剩一个结果。

例如 `2 3 4 * +`：先把 2、3、4 压栈，遇 `*` 算出 12，再遇 `+` 算出 14。`7 2 /` 得到 3.5，`2 3 -` 得到 -1。结果为小数或负数，不意味着输入语法已经支持多位数、小数或带符号数字。

求值时间为 O(n)，辅助链栈最坏为 O(n)。除零、操作数不够、结束后剩余多个数，以及非法字符均应作为错误处理，不能把不完整输入当作有效结果。
