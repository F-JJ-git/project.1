## 怎样算这道循环题

外层 `i=1..n-1`。对每一个固定的i，内层 `j=i+1..n`，因此执行 `n-i` 次，而不是n次。

```text
n=4：
i=1，j=2、3、4 -> 3次
i=2，j=3、4   -> 2次
i=3，j=4     -> 1次
总共3+2+1=6次
```

一般形式是 `(n-1)+(n-2)+...+1=n(n-1)/2`。精确次数为二次函数，渐进时间复杂度为O(n²)，不保留系数1/2和低阶项。计数器、循环变量、x都只占固定数量的空间，所以辅助空间为O(1)。

公式本身只需常数次运算，O(1)；程序保留双重循环是为了观察和核对原算法，模拟部分仍为O(n²)。不要因为最后输出公式，就认为整段程序变为O(1)。

## 边界和易错点

- `n=1` 时外层循环一次也不执行，结果是0，不是1。
- 有关联的嵌套循环应先固定外层，再数内层；不能直接机械相乘。
- 课件第46张中的 `j<i` 循环与旁边求和文字边界并不一致。按显示的 `i=0..n-1、j=0..i-1` 计算应为 `0+1+...+(n-1)`。本文件采用第56张作业的明确循环边界。
- “最坏情况”指给定输入规模下的某种输入状况；不是一见if就任意把每个分支单独取最大再相加。
- 本程序将模拟范围设为1～10000，避免过长等待；`1LL` 保证公式乘法以long long进行。
