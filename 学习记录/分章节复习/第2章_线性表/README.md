## 先记住这些区别

逻辑位序从1开始，数组下标从0开始，第 `position` 个元素对应 `data[position - 1]`。取值、赋值和删除要求 `1 <= position <= count`，插入允许到 `count + 1`。`count` 是现有元素个数，`maxSize` 是容量，两者不能互换。

顺序表插入从后向前搬移，防止覆盖尚未搬移的数据；删除从前向后搬移，填补空位。链表插入先给新结点接上原后继，再让前驱指向新结点；删除先保存待删结点，再旁路，最后释放它。课件第20、26张的“参数、空间、核心操作、属性、返回值”可以用来检查算法是否完整。

| 操作 | 顺序表 | 本章单链表与双向链表 |
| --- | --- | --- |
| 按位访问 | O(1) | O(n) |
| 查找 | O(n) | O(n) |
| 按位插入、删除 | O(n)，主要成本是搬移 | O(n)，主要成本是寻找位置；已知前驱或目标结点后改链接为O(1) |

## 按课件练习算法

### 集合运算

课件第9—12张讲并集，第28—30张讲差集，第73张布置并集和交集。程序使用课件示例 `A=(1,3,7,9,12)`、`B=(1,2,8,9,11)`，先求原始A的差集和交集，再把并集放回A：

```text
输入：1
原A-B：(3, 7, 12)
交集A∩B：(1, 9)
并集A∪B：(1, 3, 7, 9, 12, 2, 8, 11)
```

集合运算约定输入表自身不含重复元素。并集追加B中尚未出现的值，不负责排序；有序归并则保留重复值，二者不是同一个操作。复习版在写入前检查结果容量，并拒绝差集、交集的输出对象与输入对象相同，避免先清空再读取同一张表。

边界练习输入 `2`：空表取值和非法位序插入返回0；容量1的满表拒绝继续插入；容量不足的并集返回0，原A仍为 `(1)`。布尔输出0/1分别表示失败/成功。

### 单链表逆置

课件第56张交换对称位置的值，需要反复遍历链表，效率较低。本版采用第57—59张的头插法：把未处理结点逐个取出，插到同一个头结点之后。必须先保存 `cur->next`，否则修改链接后会丢失剩余链。总时间O(n)，额外空间O(1)。

```text
输入：1
初始链表：10 -> 20 -> 30 -> 40
逆置后：40 -> 30 -> 25 -> 10
链表长度：4
```

示例在逆置前还插入了25、删除了20。输入 `2` 可核对空表逆置、删除空表和单结点删空；头结点始终存在，不计入长度。

### 有序归并

课件第52张的结果为 `(2,2,3,5,8,9,11,11,15,20)`。本版用 `vector` 的下标表示两个当前位置，每轮输出较小值并推进对应下标，某一方结束后追加另一方剩余值。先检查输入非递减，算法本身不排序。

输入 `1` 得到课件结果；输入 `2` 验证空表与 `(1,1)` 归并、两个空表归并，以及拒绝无序表 `(2,1)`。本版相等时先取第一张表，课件第53张先取第二张表；对整数输出相同。课件用链表按位接口描述流程，本版顺序访问避免重复遍历，时间与结果空间均为O(n+m)。

### 约瑟夫问题

输入 `8 3`，从1号开始报1，报到3的人出列，然后下一人重新报1：

```text
出列顺序：3 6 1 5 2 8 4
优胜者：7
```

`prev` 必须始终是 `cur` 的前驱；删除当前结点后，下一位是 `prev->next`。输入 `1 1` 应直接得到优胜者1，输入 `0 3` 应报告参数必须为正。本版用 `(m-1) % remaining` 去掉无意义的整圈移动，仍保留循环链表模拟过程。最坏时间O(n²)、空间O(n)；为方便演示，人数限制为10000。

### 循环双向链表

空表满足 `head->next == head->prev == head`，遍历结束条件是回到 `head`，不是遇到空指针。插入需要更新四条链接，删除要让前驱和后继在两个方向互相接上。

输入 `1`，删除第3位的20后，正向为 `10 15 30`，反向为 `30 15 10`。输入 `2` 检查空表删除、非法插入，以及唯一结点删空。课件第70—72张还保存当前位置缓存，本版为突出链接变化省略该优化，因此按位定位依旧O(n)。

这些程序使用int简化数据元素，未逐字复制课件完整模板。管理动态结点的类禁止默认复制，防止裸指针浅拷贝导致重复释放；这与算法本身的插删规则是两个不同的知识点。
