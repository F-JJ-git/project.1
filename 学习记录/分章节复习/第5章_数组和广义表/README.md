## 地址公式

课件作业数组 `A[0:7,0:8,0:9]` 的三维长度是8、9、10，不是7、8、9。行优先时最右下标变化最快：

```text
偏移元素数 = (i*9+j)*10+k
地址 = 1000+偏移元素数*2
```

`A[1][6][8]` 偏移158个元素，起始地址为1316；数组共720个元素，总空间为1440个存储单元。只有题目明确每个存储单元为1字节时，才直接把它写成1440字节。

## 特殊矩阵的下标

本例矩阵行列从1开始，压缩数组从0开始。令矩阵阶数为n：

| 矩阵 | 有效区域 | 压缩数组下标与长度 |
| --- | --- | --- |
| 对称矩阵 | 先令i≥j | `k=i(i-1)/2+j-1`，长`n(n+1)/2` |
| 下三角矩阵 | i≥j | 0号位存公共常量c；`k=i(i-1)/2+j`，长`n(n+1)/2+1` |
| 三对角矩阵 | abs(i-j)≤1 | 0号位存带外常量c；`k=2(i-1)+j`，长`3n-1` |

下三角的上三角区域、三对角的带外区域均返回c。课件第26、29页把公共常量放在0号位，因此这两种布局与“从0开始直接存有效项”的另一种实现相差一个位置；不能混用公式。`Set()` 拒绝把公共区域某一项单独设成不同的值。

## 稀疏矩阵

三元组仅存非零元素，按行号再按列号排序，每个位置最多一项。设置新值需要找到插入位置；把已有元素设置为0则删除记录。

简单转置按原矩阵第1列、第2列……扫描，在结果中依次形成第1行、第2行……，时间为O(列数×非零项数)，而不是只交换行列号就一定完成了有序转置。

三元组加法像有序表归并：相同位置的值相加，相消为0时不保留记录，时间O(tA+tB)。乘法例子使用三重循环和线性查找，意在核对公式，未实现快速稀疏乘法；对r×k与k×c的矩阵，查找部分最坏为O(rck(tA+tB))，结果项的逐次有序插入也有成本。不能把这份演示当成只处理非零项的最优实现。

行链表中，行号由行头指针数组的位置确定，结点只存列号、值和next。查找/设置第r行的元素为O(t_r)，空间O(行数+总非零项数)。删除某行第一个结点时要改行头，不能只改局部指针。

## 马鞍点与广义表

马鞍点程序先预计算各行最小值、各列最大值，再检查所有位置，时间O(n²)，最值数组辅助空间O(n)。全为相同值的n×n矩阵有n²个马鞍点，不能每行只挑一个最小值。

广义表只数最外层的直接元素。`(a,(b,c),())` 长度3、深度2，表头是原子a，表尾是 `((b,c),())`。表尾始终是表；空表没有表头和表尾，单元素表的表尾是空表。

本解析器仅支持单个ASCII字母/数字作为原子，不支持共享子表或自引用。`()` 长0深1，`(())` 长1深2。输入上限4096字符、括号嵌套最多128层；会拒绝尾逗号、多字符原子和缺括号。

第49页将十字链表标为“不讲”，第65页将广义表存储结构标为“不讲”。这里的广义表解析树仅用于验证长度、表头表尾和深度，不是引用数法存储结构的完整实现。

每份程序独立运行。前4份保留固定演示数据，并允许一次查询或设置；不输入额外数据直接结束时，可只看演示。第5、6份按提示输入。
