## 链栈与回文

`top` 指向栈顶，入栈将新结点接到原栈顶之前；出栈先保存值和后继，再释放旧结点。入栈、出栈、判空为O(1)，释放n个结点为O(n)。拥有结点的类禁止默认浅拷贝，避免多个对象释放同一条链。

回文判断只把前一半字符入栈，再与后一半依次比较。奇数长度跳过中间唯一字符：`abcba` 中只压入a、b，跳过c，随后依次比较b、a。时间O(n)，栈空间最坏O(n)。本程序按字节比较，适合ASCII练习，大小写、空格都参与比较；不是中文Unicode回文判定器。

括号匹配遇左括号入栈，遇右括号只能与最近未闭合的左括号配对。结束时栈也应为空。空串或不含括号的文本视为匹配，其他字符被忽略；该检查不等同于完整表达式语法检查。

## 带头结点链队列

`front` 固定指向头结点，`rear` 指向最后一个有效结点。队空时二者相等；有效元素从 `front->next` 开始，头结点不保存患者数据。

入队在rear后面接新结点并更新rear；出队删除 `front->next`。如果删掉的是最后一个有效结点，必须把rear重新指向front，防止后续入队访问已释放的内存。课件第40、41页的这个边界尤其需要手画一次。

取号和叫号为O(1)，显示候诊序列为O(n)。本版菜单比作业增加了查看功能，并用0退出；号码按取号次序递增，不会因为叫完队列重新从1开始。

滑动平均是基于链队列的扩展练习，并非课件原有逐字题目。容量未满时除以实际元素数量；满时先淘汰最早的值，再追加新值。维护sum使每次均值更新O(1)，打印整个窗口仍为O(n)。普通队列满时不应自动删除数据，这里的淘汰是滑动窗口特有的业务规则。

## 循环队列的三种约定不能混用

| 方法 | 判空 | 判满 | 容量为C的数组最多存放 |
| --- | --- | --- | --- |
| 预留一个空位 | `front==rear` | `(rear+1)%C==front` | C-1个元素 |
| count计数法，本例采用 | `count==0` | `count==C` | C个元素 |
| 额外标记法 | 需结合上一次操作等状态 | 需结合额外状态 | 视具体约定 |

本程序front是队头下标，rear是下一次入队位置。空和满都可能满足 `front==rear`，所以遍历必须走count次，访问 `(front+i)%C`。课件第53页的遍历片段使用 `temPos!=rear`，若与第51页的计数法合用，就会漏掉满队列；复习版统一使用计数法。

例如容量3，压入10、20、30后front与rear都为0，但队列已满。删除10再加入40后，逻辑顺序是20、30、40。入队、出队、取头和长度为O(1)，遍历为O(count)，存储为O(C)。本例拒绝非正容量。

## 双栈中缀求值

数值栈保存操作数与已算出的子表达式结果，符号栈保存尚未执行的运算符与左括号。`* /` 的优先级高于 `+ -`；新运算符到来时，栈顶优先级大于或等于它就先归约，保证同级左结合。

归约时先弹右操作数b，再弹左操作数a，计算 `a op b`。否则减法与除法会被颠倒。右括号触发归约到左括号；结束时把剩余运算符处理完。

课件使用链栈和等号哨兵。本版用 `std::stack` 表达相同的双栈思想，支持直接回车结束，也兼容末尾一个 `=`。支持多位非负十进制数、小数、二元四则运算和圆括号；不支持一元正负号、科学计数法、隐式乘法或方括号/花括号。`expectOperand` 检查完整语法，另行检查除零与非有限结果。整体时间、辅助空间均为O(n)。

## 运行例子

各程序分别运行，表中的`/`只表示换行。

| 程序 | 输入 | 预期 |
| --- | --- | --- |
| 01 | `1 / abcba` | 是回文 |
| 01 | `1 / abca` | 不是回文 |
| 01 | `2 / {[a+b]*(c)}` | 括号匹配正确 |
| 01 | `2 / ([)]` | 括号匹配错误 |
| 02 | `1 / 1 / 3 / 2 / 2 / 2 / 0` | 先取1、2号，按1、2顺序叫号，再提示无患者 |
| 02 | `2 / 1 / 2 / 1 / 3 / 0` | 验证空队列与删空后重新入队，最后候诊号为2 |
| 03 | `3 4 / 10 20 30 40` | 平均值依次为10、15、20、30；最后窗口20→30→40 |
| 03 | `0 2` | 容量错误 |
| 04 | `1` | 显示满队列10 20 30；入队40失败；回绕后20 30 40 |
| 04 | `2` | 检查空队列、容量1、清空及非法容量 |
| 05 | `9-2*4+(8+1)/3=` | 结果4，与课件示例一致 |
| 05 | `8-3-2`、`8/4/2` | 分别为3、1，检验左结合 |
| 05 | `7/2` | 3.5 |
| 05 | `2(3)`、`2++3`、`1/0` | 报告对应语法或除零错误 |

自查时先画“空、唯一结点、多个结点”三个状态，再推演删除与重新入队；最后说明为什么修改结构后仍满足指针或计数器的不变量。
