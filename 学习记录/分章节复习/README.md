## 怎样使用这套代码复习

1. 先看本章README的课件对照，回到对应幻灯片确认定义、图示和算法条件。
2. 对一个小输入手画数组、链表或树，推演关键指针、下标或栈的变化。
3. 再读源文件中的关键步骤注释，说明循环或递归为什么正确。
4. 运行章内示例，尝试空结构、单元素、边界位置和非法输入，核对结果与复杂度。

每个源文件都保留自己的 `main()`。有的程序读取交互输入，有的直接构造一组演示数据；输入方式和预期输出见文件头及章节说明。

## Visual Studio 2022运行

单题运行：新建C++控制台项目，只加入当前需要运行的一个源文件，选择C++17与 `/utf-8`。Windows下程序会设置UTF-8控制台输出。

整套浏览：在VS2022选择“打开文件夹”，打开本目录。随附的 [CMakeLists.txt](CMakeLists.txt) 为每个 `.cpp` 建立独立目标，例如 `ch1_01`；选择需要的启动目标后运行。需要安装VS的“使用C++的桌面开发”组件及其中的CMake工具。

开发者命令提示符中也可单独编译，例如进入第1章目录：

```text
cl /nologo /EHsc /std:c++17 /W4 /utf-8 "01_嵌套循环执行次数.cpp" /Fe:count_loop.exe
count_loop.exe
```

## 注释的阅读重点

- 线性表：区分逻辑位序和数组下标；插入、删除前后哪些链接或元素需要改变。
- 栈和队列：区分栈顶、队头、下一次入队位置；统一判空判满方法。
- 数组与矩阵：先确定下标起点、存储顺序和压缩映射，再代公式。
- 树：先写空树的递归边界，再说明左右子树或孩子兄弟关系；区分树高、层数和结点数。
- 算法分析：按实际实现计算时间和辅助空间，不能把“已经找到结点后的改链接”当成完整按位查找的成本。
