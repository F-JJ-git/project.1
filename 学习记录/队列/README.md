# 循环队列学习记录

[循环队列.cpp](循环队列.cpp) 使用动态数组实现模板类 `CircQueue<ElemType>`，包含入队、出队、取队头、遍历、深拷贝和测试示例。

## 核心概念

队列遵循“先进先出”：从队尾入队，从队头出队。循环队列用取模运算让下标回到数组开头，重复利用出队后腾出的空间。

| 成员 | 含义 |
| --- | --- |
| `elems` | 存放元素的动态数组 |
| `front` | 队头元素的下标；空队列时没有可读取的队头元素 |
| `rear` | 下一次入队的位置 |
| `maxSize` | 数组容量；入队不扩容，赋值时随源队列复制 |
| `count` | 当前元素个数 |

这份实现通过 `count` 区分空和满，容量为 `maxSize` 的数组可以存放 `maxSize` 个元素，无需预留一个空位置：

```cpp
count == 0        // 队空
count == maxSize  // 队满
```

`front == rear` 可能表示空队列，也可能表示满队列，不能单独用它判空。容量大于零时，下标与长度始终满足 `rear == (front + count) % maxSize`。

## 基本操作

| 函数 | 操作与返回值 | 时间复杂度 |
| --- | --- | --- |
| `InQueue(e)` | 将元素写入 `elems[rear]`，然后 `rear = (rear + 1) % maxSize`、`count++`；满时返回 `false` | O(1) |
| `OutQueue(e)` | 将 `elems[front]` 赋给 `e`，然后 `front = (front + 1) % maxSize`、`count--`；空时返回 `false` | O(1) |
| `GetHead(e)` | 读取队头，不改变队列；空时返回 `false` | O(1) |
| `Traverse(visit)` | 从队头到队尾访问有效元素，下标为 `(front + i) % maxSize` | O(n) |
| `Length()` | 返回 `count` | O(1) |
| `Empty()` | 返回 `count == 0` | O(1) |

以上复杂度将元素赋值和单次访问视为常数时间。数组空间为 O(maxSize)。`Traverse()` 要求传入有效的访问函数；空队列的 `OutQueue()` 和 `GetHead()` 不修改输出参数。

出队只改变逻辑范围，不立即销毁数组中的对象；数组在析构或替换时释放。元素类型需要支持默认构造和复制赋值。

## 下标回绕示例

主程序的 `q1` 容量为 5：

| 操作完成后 | `front` | `rear` | `count` | 从队头到队尾 |
| --- | --- | --- | --- | --- |
| 初始化 | 0 | 0 | 0 | 空 |
| 入队 10、20、30 | 0 | 3 | 3 | 10 20 30 |
| 出队 10 | 1 | 3 | 2 | 20 30 |
| 入队 40 | 1 | 4 | 3 | 20 30 40 |
| 入队 50 | 1 | 0 | 4 | 20 30 40 50 |

`rear` 回到 0 后，下一次入队就会使用数组开头的位置。遍历和复制必须按循环下标访问，不能直接把数组的前 `count` 个位置当成队列内容。

## 深拷贝与赋值

```cpp
CircQueue<int> q3(q1); // 复制构造：创建一个新队列
q2 = q1;              // 赋值：替换一个已有队列
q1 = q1;              // 自赋值：保持原内容
```

复制构造和赋值都分配独立数组，并复制容量、`front`、`rear`、`count`，再将有效元素复制到相同的循环位置。修改副本不会影响源队列。因为类直接管理动态数组，需要配套实现析构函数、复制构造函数和复制赋值运算符，避免默认的指针复制导致重复释放内存。

整理版保留原有算法、类结构及演示流程，统一格式，增加负容量检查。复制时用临时 `unique_ptr` 管理新数组；分配和复制全部成功后，才替换目标队列的旧数组。如果元素复制抛出异常，临时数组会被释放，赋值目标保持原状。

负容量抛出 `invalid_argument`。零容量允许创建，入队直接返回失败；出队和取队头也返回失败，遍历不访问任何元素，因此不会执行除以零的取模运算。

## 运行结果

在 Visual Studio 2022 的 C++ 控制台项目中编译 `循环队列.cpp`，启用 `/utf-8`。源码要求 C++11 或更高版本；中文输出需要终端采用 UTF-8，例如先执行 `chcp 65001`。也可以在 Visual Studio 开发者命令提示符中进入源码目录后执行：

```text
cl /EHsc /W4 /std:c++17 /utf-8 "循环队列.cpp"
```

主程序输出：

```text
q1原始队列：20 30 40 50
自我赋值后q1：20 30 40 50
赋值后q2：20 30 40 50
q2出队元素：20
修改后q2：30 40 50 60
再次查看q1：20 30 40 50
```

`q2` 修改后，`q1` 保持不变，说明赋值复制出的数组相互独立。与顺序栈的“后进先出”相比，队列总是先取出最早入队且尚未出队的元素。
