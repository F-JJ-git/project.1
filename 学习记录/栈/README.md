# 顺序栈学习记录

[顺序栈.cpp](顺序栈.cpp) 使用动态数组实现模板类 `SqStack<ElemType>`，包含基本操作、深拷贝和测试示例。

## 存储方式

- `elems` 指向存放元素的数组，`maxSize` 表示容量，`count` 表示当前元素个数。
- 栈底是 `elems[0]`，非空时栈顶是 `elems[count - 1]`。
- 入栈先写入 `elems[count]` 再增加 `count`；出栈先取出栈顶再减少 `count`，体现“后进先出”。
- 容量固定，不自动扩容。负容量抛出 `invalid_argument`；零容量允许创建，但入栈总是失败。

## 成员函数

| 函数 | 作用 | 说明 |
| --- | --- | --- |
| `Push(e)` | 入栈 | 栈满返回 `false` |
| `Pop(e)` | 取出并删除栈顶元素 | 空栈返回 `false`，不修改输出参数 |
| `Top(e)` | 读取栈顶元素 | 不删除元素，空栈返回 `false` |
| `Empty()` | 判断是否为空 | 等价于 `count == 0` |
| `Length()` | 获取元素个数 | 返回 `count` |
| `Clear()` | 逻辑清空 | 将 `count` 置零，保留容量 |
| `Traverse(visit)` | 访问所有有效元素 | 从栈底到栈顶；传入有效的访问函数 |

在元素赋值视为常数时间时，基本操作为 O(1)，遍历为 O(n)。数组空间为 O(maxSize)。`Clear()` 和 `Pop()` 只改变有效元素范围，不立即销毁数组中的对象；数组在析构或替换时释放。元素类型需要支持默认构造和复制赋值。

## 复制构造与赋值

```cpp
SqStack<int> s2 = s1; // 创建新对象，调用复制构造函数
s3 = s1;             // 给已有对象赋值，调用赋值运算符
```

两种复制都重新分配数组，并复制有效元素和容量，因此各个栈的存储相互独立。类直接管理动态数组，需要同时实现析构函数、复制构造函数和复制赋值运算符，避免默认的指针复制导致多个栈释放同一块内存。

整理版保留了原有算法和示例，统一了格式，补充容量检查；复制时用临时 `unique_ptr` 管理新数组，成功后才交给栈。如果分配或元素复制失败，临时内存会被释放，赋值目标的原内容也不会被提前删除。赋值运算符检查 `this != &source`，支持 `s = s`。

## 运行示例

在 Visual Studio 2022 的 C++ 控制台项目中编译 `顺序栈.cpp`，启用 `/utf-8`。源码要求 C++11 或更高版本；中文输出需要终端采用 UTF-8，例如先执行 `chcp 65001`。也可以在 Visual Studio 开发者命令提示符中进入源码目录后执行：

```text
cl /EHsc /W4 /std:c++17 /utf-8 "顺序栈.cpp"
```

测试主程序依次演示入栈、取顶、出栈、复制构造、赋值和清空，输出如下：

```text
s1遍历：10 20 30
s1长度：3
栈顶元素：30
出栈元素：30
复制后s1：10 20
复制后s2：10 20 40
赋值后s3：10 20
清空后s3长度：0
```

`Traverse()` 的输出顺序是栈底到栈顶，不能把它当作出栈顺序。若依次压入 10、20、30，再连续出栈，顺序应为 30、20、10。
